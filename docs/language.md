# 语言规范

## 文字

文档, 注释, 提交信息与界面文案都面向资深开发者, 直接写结论与约束. 不寒暄, 不解释常识, 不使用感叹号与反问句.

正文使用英文标点, 不使用顿号, 全角逗号与句号. 不使用箭头与 emoji, 流向与因果用文字表述. 中文与西文, 数字之间留一个空格.

标题使用短语. 一段只表达一个意思. 除确实并列且超过三项, 不使用列表. 同一概念固定使用一个词.

## 注释

能由命名说明的内容不加注释. 注释只使用单行注释与文档注释, 不使用普通多行注释.

文档注释首行写一句话简述, 其余用标签补充参数与返回值. 接口与类的每个字段写一行文档注释.

成对区块标记只用于分组大量并列条目.

## 内容边界

只写已确认的约定. 不根据推断补充条款, 不把实现细节写成要求. 未确定的内容留在任务区.
