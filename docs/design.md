# 设计

## 样式方案

只按亮色设计, 深色由色阶自动反转, 不为深色单独编写样式. 色阶与语义档位在 `tune.config.ts` 中定义, 对应的工具类位于 `src/styles/`.

前景色按重要程度分为 soft, default, strong 三档, 背景默认使用 `bg-default`, 卡片等内容层使用 `bg-strong`.

反色档仅用于整块强调面, 不用于细粒度的文字着色; 中性色不提供反色背景, 需要时使用主色或错误色的反色档.

尺寸使用 tunewind 的单位体系: 无后缀按四像素一档, `x` 为一像素, `h` 为半个字号, `r` 为一个字号.

不应先换算像素再选取近似值, 也不得使用小数与分数类名, wxss 不支持类名中的转义字符, 会直接导致编译失败.

图标尺寸由外层容器控制, 图标取容器的百分之百. 图标颜色只能通过色值属性传入, 语义色与强调色集中在 `src/config/theme.ts`, 使用十六进制.

动态拼接的类名不会被扫描, 必须写成字面量或通过查表得到.

## 页面与弹层

每个页面由 `Page` 包裹 `Main`, 两者均位于 `src/components/layout/`, 不得将内容直接放入 `Page`.

安全区, 底栏, 提示层与模态层由 `Page` 统一挂载, 页面只决定是否启用.

左右内边距由 `Main` 提供, 上下内边距由页面提供; 整页滚动时, 上下内边距应放入滚动区域内部.

组件使用函数声明, 参数解包, 类型以 `Readonly` 包装, 返回值显式标注 `ReactNode`. 需要透传或对齐 Taro 组件属性时, 直接取用组件属性的类型.

弹层挂载到 `src/components/modal/` 提供的模态层, 不使用固定定位, 也不在页面内自行实现遮罩与入场动画.

底部信息使用 `Popup`, 居中确认使用 `Alert`, 操作确认使用 `Dialog`, 锚定操作项使用 `Menu`.

列表行使用 `Cell`, 按钮使用 `Button`, 卡片使用 `Card`, 表单控件使用 `src/components/form/` 下的组件, 不应重复实现. 空态与加载态使用一行文案.

## 表单

表单由 zod 结构驱动, 容器位于 `src/components/form/`. 字段只声明名称与类型, 校验规则写在结构中, 控件不重复判断.

提交时统一取值与校验, 错误回填到对应字段, 不使用全局提示.

字段通过 hook 注册到表单, 提供当前值与校验结果, 控件只负责渲染与变更.
