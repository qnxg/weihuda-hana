# 架构与约定

## 目录与命名

`contract` 位于仓库根, 存放前后端共享的接口契约, 仅包含类型与端点声明. `server` 是契约的 mock 实现, 不进入小程序产物. `shared` 存放两端共用的码表与环境解析, 前端代码全部在 `src`.

目录按业务域划分, 文件名只描述自身职责, 不重复所属业务域. 页面内部按目录区分视图, 状态, 派生与数据, 新增模块沿用已有分工, 不另开一套.

导出的常量使用全大写; 成组常量收进对象, 对象名全大写, 内部各级用驼峰, 层级应尽量浅. 类型与组件使用 PascalCase, 构建期配置不受此约束.

导入一律使用 `@` 别名开头的绝对路径, 不写扩展名, 不使用相对路径. 类型导入与值导入分开书写, 顺序交由 lint 处理.

## 状态归属

服务端数据只保留一份, 统一交由 TanStack Query 管理, 不在 store 或组件内另存副本. 修改成功后失效对应的查询键.

查询键集中在 `src/config/query.ts`, 由业务域与学期组成, 不在调用处手写数组.

store 位于 `src/stores/`, 只存放状态与设值函数, 不承载业务逻辑. 需要组合状态, 发起请求或处理副作用时, 由 hook 读取 store 后再交给组件.

仅页面自身使用的选中项, 展开态与长按位置保留在本地; 只有需要被其他页面指定, 且跨页后仍需保留的状态才进入 store.

学期, 周与展示模式属于课表页的数据状态, 不因其他页面需要跳转而提升为全局状态.

## 页面与跳转

所有跳转必须经由 `src/utils/navigate.ts` 的 `navigateTo`, 不得直接调用 Taro 的跳转接口. 页面路径统一登记在 `src/config/page.ts`, 代码中不得出现字面量路径.

tab 页不支持查询串, 因此带内部视图的页面在 `src/config/page.ts` 中登记为对象: `index` 为真实路由, 其余键为附带视图参数的完整路径.

调用方书写视图键, 由 `navigateTo` 拆出路由与参数后交由该页面的登记项处理.

页内视图的当前值存放在该页面自己的 store 中, 跨页指定时先写入 store 再切换页面; 不带参数进入时保留上次的视图.

返回统一使用 `navigateBack`, 它在页面栈为空时回退到首页, 页面不应自行判断页面栈.
